Como Instalar o FAQ no seu Tema TRAY

          
Siga este passo a passo se sua loja ainda não possui os arquivos de FAQ instalados

        

        
      


      

        

          
💡

          

            Como funciona a arquitetura TRAY? O sistema de FAQ utiliza 2 snippets na pasta snippets/ do tema, carregados no final do arquivo da Categoria (pages/catalog.html). O processo leva menos de 5 minutos!
          

        


        


          
          

            

              Passo 1
              
Ativar as chamadas no arquivo da Categoria (pages/catalog.html)

            

            
Painel Tray ➔ Loja Virtual ➔ Meus Temas ➔ Ações ➔ Editar Código ➔ Pasta pages/ ➔ catalog.html

            
Role até o final do arquivo catalog.html e insira as 2 chamadas de snippet abaixo:

            

              
              
{# Chamada dos snippets de FAQ e Schema no final da página de Categoria (PLP) #}
{% element 'snippets/faq-categorias' %}
{% element 'snippets/faq-schema' %}

            

          


          
          

            

              Passo 2
              
Criar o arquivo do Accordion (snippets/faq-categorias.html)

            

            
Editar Código ➔ Pasta snippets/ ➔ Novo Arquivo ➔ Nome: faq-categorias.html

            
Crie este arquivo e cole a estrutura do Accordion visual + script que recebe os dados gerados pela nossa ferramenta:

            

              
              
<div class="faq-container-plp">
  <div class="container">
    <div id="faq-content"></div>
  </div>
</div>

<script>
  // Dicionário de FAQs por ID de Categoria
  const faqsPorCategoria = {
    // Cole aqui o código JS gerado por esta ferramenta para cada categoria!
  };

  const categoriaId = '{{ category.id }}';

  if (faqsPorCategoria[categoriaId]) {
    const faqData = faqsPorCategoria[categoriaId];
    const container = document.getElementById('faq-content');
    
    let html = '<div class="faq-accordion-wrap">';
    html += '<h2 class="faq-section-title">Perguntas Frequentes</h2>';
    
    faqData.forEach((item) => {
      html += `
        <div class="faq-item">
          <button class="faq-question" onclick="toggleFaq(this)">
            <span>${item.pergunta}</span>
            <span class="faq-icon">+</span>
          </button>
          <div class="faq-answer">
            <div class="faq-answer-inner">${item.resposta}</div>
          </div>
        </div>
      `;
    });
    html += '</div>';
    container.innerHTML = html;
  }

  function toggleFaq(btn) {
    const item = btn.parentElement;
    const isOpen = item.classList.contains('active');
    document.querySelectorAll('.faq-item').forEach(el => el.classList.remove('active'));
    if (!isOpen) item.classList.add('active');
  }
</script>

<style>
  .faq-container-plp { padding: 40px 0; background: #ffffff; }
  .faq-section-title { font-size: 24px; font-weight: 700; margin-bottom: 24px; text-align: center; color: #111111; }
  .faq-accordion-wrap { max-width: 840px; margin: 0 auto; }
  .faq-item { border-bottom: 1px solid #e2e8f0; margin-bottom: 12px; }
  .faq-question { width: 100%; display: flex; justify-content: space-between; align-items: center; padding: 18px 0; background: none; border: none; font-size: 16px; font-weight: 600; text-align: left; cursor: pointer; color: #1e293b; }
  .faq-icon { font-size: 22px; font-weight: 400; transition: transform 0.3s ease; color: #f97316; }
  .faq-item.active .faq-icon { transform: rotate(45deg); }
  .faq-answer { max-height: 0; overflow: hidden; transition: max-height 0.35s ease; }
  .faq-item.active .faq-answer { max-height: 600px; }
  .faq-answer-inner { padding-bottom: 20px; color: #475569; font-size: 14.5px; line-height: 1.7; }
</style>
